Источники и лицензии

Sources and licenses · Gearbox visualization

Интерактивный редуктор создан из нашей демонстрационной сборки FreeCAD с четырьмя шестернями и передаточным отношением 4:1. Для публичного просмотра мы экспортировали полигональную геометрию в формат GLB. Это не исходный параметрический файл, не спецификация для изготовления и не готовое изделие.

This is a triangulated viewer export of our four-to-one FreeCAD gearbox experiment, not the editable CAD source or manufacturing documentation.

Шестерни / Gears — CC0

  • Innerscene — Module 2, 20-tooth involute spur gear. CC0 / Public Domain.
  • Innerscene — Module 2, 40-tooth involute spur gear. CC0 / Public Domain.

Шестерни были доработаны для сборки (отверстия, соединения и посадочные элементы), а затем триангулированы для отображения в браузере.

The public mesh contains modified and triangulated derivatives of these CC0 gear shapes.

Подшипники и крепёж / Bearings and fasteners

В исходном приватном CAD-проекте использовались детали из FreeCAD Parts Library, опубликованные под CC BY 3.0. Для данной веб-сцены импортированные тела библиотечных подшипников и винтов были исключены и заменены упрощёнными геометрическими элементами. Ссылка на библиотеку приведена для полноты происхождения оригинальной сборки.

The private source assembly used FreeCAD Parts Library assets (CC BY 3.0). Those imported bearing and screw solids have been excluded from the public GLB and replaced with simplified geometry. This credit acknowledges the origin of the private experiment.

Тестовые фото-материалы / Photo-scanned materials

В экспериментальном режиме ?scan=1 краска рамы может использовать Blue Metal Plate — настоящую сфотографированную поверхность окрашенного металла, автор Rob Tuytel, Poly Haven, лицензия CC0 1.0. Режим используется только при явном включении; исходная поверхность — металлические ворота, а не рама редуктора. Материал подгружается с Poly Haven; основной режим сайта внешние текстуры не запрашивает.

Optional photographed texture preview: Blue Metal Plate, Rob Tuytel / Poly Haven, CC0 1.0. The source is a photographed industrial gate, not an authentic motor or gearbox coating.

Двигатель / Motor

Оригинальная OEM-модель двигателя Pololu 4692 не включена в опубликованный GLB. Видимые корпус и вал двигателя — простые условные цилиндры. Это независимая учебная визуализация, не одобренная и не сертифицированная Pololu.

The manufacturer's original CAD body and output shaft are not distributed. Generic placeholder cylinders represent the motor and output shaft. No manufacturer endorsement is implied.

О модели / About this model

Показано 74 отдельных геометрических объекта, включая условные компоненты. Вращение трёх валов соответствует кинематическому отношению +1 : −1/2 : +1/4. Изменение оборотов на странице — кинематическая демонстрация, не расчёт нагрузки, износа или безопасности. Публичный файл gearbox-public.glb может быть скачан из браузера.

74 displayed mesh objects, including simplified parts. Rotation ratios are +1 : −1/2 : +1/4. Shaft speeds illustrate kinematics only. The publicly served GLB can be downloaded.
